An AI-powered web application that automatically generates university-style exam question papers from a given syllabus using Google Gemini and Streamlit. The system helps students and educators quickly create practice exams based on difficulty level and marks distribution.

Features

Upload syllabus in PDF format
Select exam difficulty (Easy, Medium, Hard)
Choose exam type (50, 75, or 100 marks)
Automatically generate structured exam question papers
Download generated question paper as a file
Powered by Google Gemini Generative AI

Working
1. User uploads syllabus PDF  
2. Text is extracted from the PDF  
3. A prompt is constructed using:
   - Syllabus
   - Difficulty level
   - Marks format  
4. The prompt is sent to Google Gemini  
5. Gemini generates a complete exam paper  
6. The result is displayed and downloadable
